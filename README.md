# Mini Healthcare Support Web App

## Overview

The Mini Healthcare Support Web App is a simple healthcare assistance portal that allows patients to submit their details and healthcare concerns. The system automatically generates an AI-inspired summary based on the symptoms entered by the user.

## Features

* Patient Support Form
* Appointment Booking Information
* Dynamic Appointment Fields
* AI-Based Health Summary Generator
* Symptom-Specific Recommendations
* Responsive User Interface

## Tech Stack

* HTML5
* CSS3
* JavaScript

## AI / Automation Idea

The application includes an AI-inspired Healthcare Summary Generator. Based on the patient's concern, the system analyzes keywords such as fever, headache, vomiting, body pain, motions, and general checkups. It then automatically generates a relevant assessment and recommended next steps.

## NGO Use Case

Healthcare NGOs can use this application to collect patient information and automatically organize healthcare concerns before review by volunteers or medical professionals. This helps streamline patient intake and improve support efficiency.
